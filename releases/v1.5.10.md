# hwmonitor-fnos v1.5.10

**正式稳定版。已在 N5A / F8NAB、fnOS `6.18.18.c1107-trim` 完成真实本机编译、实际模块加载和风扇节点验收。**

## 根因

fnOS 将应用安装到 `/volX/@appcenter/<app>`，实际文件/目录可由平台设置为 `root:root` 且带 group-write/ACL，例如 `rwxrwxr-x+`。1.5.9 将随 FPK 安装的 `drivers/n5-src` 误套用宿主 Kbuild 的严格权限规则，因此在真实 N5A/c1107 上即使完整 headers、Module.symvers、GCC 12.2.0 和 kmod 均存在，也会在执行 make 前报：

```text
构建路径权限不可信: /vol1/@appcenter/hwmonitor/drivers/n5-src
```

## 修正

- 随包驱动源码与宿主 Kbuild 分离信任策略。
- 随包源码必须位于 appDir 固定子目录、不得是 symlink/越界路径，并对**实际读入字节**执行策略 SHA256 校验。
- 不再要求 fnOS 应用目录自身必须 0755 或禁止 group-write/ACL。
- 宿主 kernel build tree、headers、GCC/ld 和 root 私有缓存继续要求 root 所有且不可被 group/other 写入。
- 本机编译路径、远程 fallback、驱动 0.2.0、温度映射、风扇曲线和 UI 均不做其他修改。
- 不执行 apt，不修改 `/lib/modules`、`modules-load.d`。

## 验证

新增回归用 0775 目录与 0664 文件模拟 fnOS 应用安装权限：正确 SHA256 必须允许编译；源码被篡改或替换为 symlink 仍必须拒绝。保留 1.5.9 的真实 c1032/c1126 Kbuild/modinfo 集成验证和所有 1.5.8 回归。

CI 本身仍不执行真实 N5A `insmod`/PWM；正式发布前已补充真实 NAS 验收。
