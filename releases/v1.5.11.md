# hwmonitor-fnos v1.5.11（正式稳定版）

针对 fnOS `6.18.18.c1126-trim` 实机报错：

```text
驱动文件类型/权限/大小无效: minisforum_n5_it5571-6.18.18.c1126-trim.ko
```

实机 SSH 确认内置 `.ko` 为 root:root、`-rwxrwxr-x`、426312 字节、nlink=1。1.5.10 使用缓存文件权限校验检查随 FPK 安装的驱动，因 group-write 而拒绝；并且在 `policy.bundled[kernel]` 命中时，异常不会降级到本机编译/远程通道。

### 修复

1. 内置 `.ko` 允许 fnOS 安装的 group-write 权限，但绝不直接用这个可变路径 `insmod`；先读入并写入 root 私有临时 `.ko`，之后进行完整 SHA256、ELF、modinfo 与内核身份校验，再加载。
2. 内置模块缺失、损坏或验证失败时自动尝试本机精确 headers 编译；本机失败再走 `kernel-modules-v2` 下载。
3. 远程缓存、本机缓存和临时模块仍采用严格 root 权限规则；临时文件在正常加载、失败及取消后清理。
4. 不改 N5 0.2.0 C 驱动、已有温度映射、风扇曲线、PWM 安全下限及 UI。

### 验证结果

CI 通过 63 项 Node 测试、39 项 Python 测试、真实 c1032/c1126 headers/Kbuild 检查及最终 FPK 反向验证。CI 不执行真实硬件操作。
